# C Beginner Projects

Small C projects I built while learning.

- `number_guessing_game.c` – guess a random number
- `todo_list.c` – command-line task manager
- `temperature_converter.c` – Celsius/Fahrenheit converter

Compile and run:
gcc filename.c -o program
./program
